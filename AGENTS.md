# RunParity contributor guidance

RunParity is an evidence-first environment diagnosis tool. Prefer narrow, falsifiable claims over confident guesses. Never turn an observed correlation into a verified intervention without the required isolation and A/B/A ledger.

## Agent skills

### Issue tracker

Work is tracked in this repository's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix` labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository: read root `CONTEXT.md` and relevant records in `docs/adr/` before changing behavior. See `docs/agents/domain.md`.
