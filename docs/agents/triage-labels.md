# Triage labels

The engineering workflow uses these exact GitHub label strings.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the report. |
| `needs-info` | `needs-info` | The reporter must provide missing evidence. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an autonomous agent. |
| `ready-for-human` | `ready-for-human` | Requires human judgment, credentials, hardware, or coordination. |
| `wontfix` | `wontfix` | Intentionally will not be actioned. |

Do not create synonymous labels. A product-area, severity, or platform label may coexist with exactly one workflow-state label.
